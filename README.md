# Neha Bhati — Portfolio

A responsive, animated portfolio for GitHub Pages. Built with plain HTML, CSS and JavaScript.

## Features
- Responsive layout for desktop, tablet and mobile
- Dark and light themes (preference saved in the browser)
- Scroll reveal animations and reading progress indicator
- Demon Slayer / Black Clover-inspired atmosphere using original abstract motifs, not character artwork
- About, skills, experience, projects, education, certification and contact sections

## Deploy on GitHub Pages
1. Create a new public GitHub repository, for example `neha-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/neha-portfolio/`.

## Before publishing
- Confirm your LinkedIn URL and GitHub profile URL are correct.
- Review the CV-derived project descriptions and role details for accuracy.
- The portfolio intentionally does not include or upload either CV.
- No backend or build step is required.
